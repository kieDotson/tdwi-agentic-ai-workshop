# Lab 1 — Reconciliation Agent

In this lab, you will build a low-code reconciliation investigator in Langflow for Morrow Peak Outfitters.

## Start Here

Open the attendee guide and follow the lab instructions:

`attendee-guide/lab-1-reconciliation-agent-guide.pdf`

## Files

- `attendee-guide/` — full step-by-step lab instructions
- `data/` — Finance and Sales Q3 reconciliation extracts
- `reference-flow/` — completed Langflow flow for troubleshooting or recovery

## If You Get Stuck

Use the troubleshooting section in the attendee guide first.

If you are unable to get your flow working during the lab, import the completed flow from `reference-flow/` and continue with the exercise.

After importing the reference flow, configure the workshop Gemini API credential before running it.
